# 필체크 (PillCheck)

> 여러 약을 함께 복용할 때의 위험을 **식약처 공식 데이터(DUR)**로 확인하는 서비스.
> 병용금기 · 성분 중복 · 다제약물 · 노인주의를 한 번에 점검하고,
> 위험이 확인되면 가까운 약국·병원 상담으로 연결합니다.

《요즘 바이브 코딩》 챕터 8·9·10 실습을 **하나의 모노레포**로 통합하고,
약물-약물 상호작용에 집중한 포트폴리오 프로젝트입니다.

## 왜 하나로 묶었나

각 챕터를 따로 만들면 "실습 3개"로 끝나지만, "약물 안전"이라는 하나의
목적으로 묶으면 **하나의 제품**이 됩니다.

```
[08 랜딩]    서비스 소개 → 약 상호작용 확인으로 안내
[09 블로그]   약물 안전 정보 콘텐츠 (Supabase + RLS)
[10 챗봇]    약물 상호작용 상담 (RAG + 4축 엔진)
[11 약국지도] 위험 확인 시 주변 약국·병원 상담 연결 (카카오 지도)
[음성]       약 이름을 말하면 상호작용 확인 (STT/TTS)
                 └─ 모두 packages/shared 의 4축 약물 엔진을 공유
```

## 핵심: 4축 약물 상호작용 엔진

이 서비스의 심장부입니다. 여러 약을 함께 복용할 때의 위험을 4개 축으로 봅니다.

| 축 | 무엇 |
| --- | --- |
| 1. 병용금기·주의 | 두 약을 함께 쓰면 안 되는/조심할 조합 |
| 2. 효능군·성분 중복 | 같은 계열·성분이 겹쳐 과용량 되는 위험 |
| 3. 다제약물 | 약이 3·4개↑ 늘수록 상호작용 쌍이 급증 |
| 4. 노인·연령 주의 | 특정 연령대에 주의가 필요한 약 |

여기에 더해, 직업·나이·생활패턴(교대근무·장시간·수면부족 등)별로 **부족하기 쉬운
영양소를 안내**하고, 그 영양제가 복용 약과 충돌하는지(예: 오메가3+와파린)도
함께 점검합니다. (치료·예방 표방이 아닌 일반 정보 참고)

```bash
cd packages/shared/engine
python3 drug_interaction.py
```

**판정의 공식 근거는 식약처 DUR API**입니다. 임의 판단을 하지 않으며,
시너지(효과 증강)는 처방 영역이라 다루지 않고 위험만 안내합니다.
자세한 내용은 `packages/shared/README.md`, 근거는 `packages/shared/SOURCES.md`.

> ⚠️ 의료기기가 아니며 진단·처방을 하지 않습니다. DB 미등재가 안전을 의미하지
> 않으며, 최종 판단은 의사·약사가 합니다.

## 폴더 구조

```
pillcheck/
├── README.md / CLAUDE.md
├── apps/
│   ├── 08-saas-landing/     ← 랜딩 (✅ 완성 코드, Next.js)
│   ├── 09-health-blog/      ← 약물 안전 블로그 (Supabase)
│   ├── 10-review-chatbot/   ← 약물 상담 챗봇 (RAG)
│   ├── 11-pharmacy-map/     ← 약국·병원 지도 (카카오)
│   └── voice-assistant/     ← 음성
├── packages/shared/         ← 4축 약물 엔진 + DUR 클라이언트
├── archive/                 ← 이번 범위 제외(음식 관련) 보관
└── docs/                    ← 개발 순서·가이드
```
