# 음성 비서 (Voice Assistant)

10번 챗봇을 **음성으로** 쓸 수 있게 하는 모듈. 고령자는 타이핑보다 말이 편하므로,
음성 접근이 이 플랫폼에서 자연스러운 확장입니다.

## 무엇을 만드나

- 음성 입력(STT) → 텍스트로 변환 → 10번 챗봇에 질문
- 챗봇 답변 → 음성(TTS)으로 읽어주기
- "타이레놀이랑 혈압약 같이 먹어도 돼요?"를 말로 묻고 답을 듣는 흐름

## 왜 이 플랫폼에 맞나

고령자 타깃이라 음성이 핵심 접근성 수단입니다. 별도 서비스가 아니라
**10번 챗봇의 음성 프런트엔드**로 붙이는 게 가장 자연스럽습니다.

## 스택 (선택지)

- 브라우저 내장 Web Speech API (가장 간단, 설치 없음)
- 또는 STT/TTS API (더 정확하지만 키 필요)
- 백엔드: 10번 챗봇의 `/chat` 재사용

## 개발 가이드

Claude Code 프롬프트는 [`PROMPTS.md`](./PROMPTS.md) 참조.

## 참고

음성은 별도 레포로 빼지 않고 여기(플랫폼 안)에 두는 게 맞습니다.
10번 챗봇과 백엔드를 공유하기 때문입니다.
