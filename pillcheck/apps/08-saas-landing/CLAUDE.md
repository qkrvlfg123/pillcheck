# CLAUDE.md — 08 SaaS 랜딩 페이지

## 이 앱의 목표
실버케어 플랫폼 서비스 소개 랜딩 페이지. 방문자를 블로그·챗봇으로 안내.

## 스택
- Next.js + TypeScript + Tailwind CSS
- 배포: Vercel
- 디자인 기준: Stitch 시안

## 규칙
- 페이지는 랜딩 한 개. 라우팅·상태관리 복잡하게 만들지 말 것.
- 고령자 대상: 기본 폰트 ≥18px, 고대비, 큰 버튼, 쉬운 문장.
- 하단에 "의료기기 아님, 참고용" 고지 필수.
- TDD·클린아키텍처 쓰지 않음 (가볍게).

## 명령어
- `npm run dev` : 로컬 개발
- `npm run build` : 빌드(배포 전 반드시 통과 확인)
