# 08 랜딩 — Claude Code 프롬프트 가이드

Claude Code를 켜고 아래 프롬프트를 순서대로 사용하세요. 각 단계 끝나면
결과를 확인하고 다음으로 넘어갑니다. `[대괄호]`는 본인 내용으로 바꾸세요.

---

## 0단계 · 준비

먼저 Stitch(https://stitch.withgoogle.com)에서 랜딩 시안을 만드세요.
프롬프트 예시:

> 고령자를 위한 헬스케어 플랫폼 'SilverCare'의 랜딩 페이지를 디자인해줘.
> 큰 글씨, 높은 대비, 따뜻한 색감. 히어로 섹션에 "복잡한 디지털, 쉽게
> 이어드립니다" 같은 카피와 CTA 버튼. 아래에 3가지 기능(건강정보 블로그,
> 약물 상담 챗봇, 음성 안내) 카드.

시안이 나오면 스크린샷 또는 export한 코드를 준비합니다.

---

## 1단계 · 프로젝트 초기화

```
이 폴더에 Next.js 랜딩페이지 프로젝트를 만들어줘.
- TypeScript, Tailwind CSS 사용
- 페이지는 한 개(랜딩)만 필요, 라우팅 복잡하게 하지 마
- 고령자 대상이라 기본 폰트 크기를 크게(최소 18px), 고대비로
- 먼저 폴더 구조와 설치할 패키지 계획을 말해주고, 내가 확인하면 진행해
```

## 2단계 · Stitch 시안 반영

Stitch에서 만든 시안 스크린샷을 첨부하고:

```
이 스크린샷이 Stitch에서 만든 랜딩 시안이야.
이걸 기준으로 히어로 섹션부터 구현해줘.
- 카피: "[본인 서비스 한 줄 소개]"
- CTA 버튼 2개: "건강정보 보러가기", "약 상담 시작하기"
- 색감과 여백은 시안을 최대한 따라줘
```

## 3단계 · 기능 소개 섹션

```
히어로 아래에 기능 소개 3카드를 추가해줘.
1) 건강정보 블로그 — 고령자 눈높이 건강 콘텐츠
2) 약물 상담 챗봇 — 여러 약을 함께 먹어도 되는지 확인
3) 음성 안내 — 말로 물어보고 들을 수 있음
각 카드에 아이콘, 제목, 한 줄 설명. 클릭하면 해당 서비스로 이동(지금은 #).
```

## 4단계 · 접근성 · 반응형 마무리

```
접근성과 반응형을 점검해줘.
- 모바일에서 카드가 세로로 쌓이게
- 버튼·링크는 손가락으로 누르기 쉽게 충분히 크게
- 색 대비가 WCAG AA를 넘는지 확인
- 하단에 "본 서비스는 의료기기가 아니며 참고용입니다" 고지 추가
```

## 5단계 · 배포

```

build가 에러 없이 되는지 먼저 확인하고, 배포 방법을 알려줘.
```
