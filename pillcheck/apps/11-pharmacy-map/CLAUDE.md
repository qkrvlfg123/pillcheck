# CLAUDE.md — 11 약국·병원 지도

## 이 앱의 목표
주변 약국·병원을 지도에 표시해, 약물 상호작용 상담으로 연결.

## 스택
- 카카오 로컬 API (약국 PM9, 병원 HP8) + 카카오맵 JS SDK
- (선택) 공공데이터 전국 약국/병원 정보

## 핵심 규칙
- 필체크 흐름의 마지막 단계: 위험 확인 → 약국/병원 상담 유도.
- 위치정보는 저장하지 않고 조회에만 사용.
- 영업/진료 시간은 부정확할 수 있으니 단정하지 말고 "방문 전 확인" 안내.
- 카카오맵 출처·로고 규정 준수.
- API 키는 .env, git 금지. JS 키 도메인 제한.

## 연계
- 10 챗봇 / 음성에서 위험이 나오면 ?from=pillcheck&risk=high 로 유입 → 안내 배너.
