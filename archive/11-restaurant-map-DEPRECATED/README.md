# 11 · 맞춤 맛집 지도

지도에서 주변 맛집을 찾고, **내 질환·복용약 기준으로 뭘 피하고 뭘 고를지**
안내받는 서비스. 이 플랫폼의 데이터셋이 실제 위치 서비스와 만나는 지점입니다.

## 무엇을 만드나

1. 지역·역명으로 주변 맛집 검색 (지도에 마커 표시)
2. 사용자 프로필(질환·복용약) 입력
3. 각 맛집의 카테고리/메뉴를 프로필 기준으로 필터링
   - 역류성식도염 → 튀김·마라 집에 "자극적일 수 있어요" 경고
   - 통풍전단계 → 곱창·맥주 집에 주의 표시
   - 순한·담백한 집을 우선 추천
4. 왜 추천/주의인지 이유를 함께 표시

## 왜 이 프로젝트인가 (플랫폼 하이라이트)

기존 맛집 지도는 "평점 높은 집"만 보여줍니다. 이 서비스는 **"나에게 맞는 집"**을
보여줍니다. `packages/shared`의 질환-음식 규칙(고령자 + 직장인)을 실제 지도
검색 결과에 적용하는 게 핵심이자 차별점입니다.

## 스택

- **카카오 로컬 API** — 키워드로 맛집 검색 + 좌표 + 카테고리 (국내 맛집에 최적)
- 카카오맵 JavaScript SDK — 지도·마커 표시
- 필터링 엔진: `packages/shared` 의 질환-음식 규칙
- (선택) 네이버 지역검색 API — 보조 채널

### 왜 카카오인가
카카오 로컬 API가 "강남역 맛집" 같은 키워드 검색 + 좌표 반환 + 카테고리
분류에 국내 맛집 대응이 가장 낫습니다. 네이버 지역검색은 결과가 최대 5건이라
목록 서비스엔 제약이 큽니다.

## 데이터 연결

카카오가 주는 식당 **카테고리**(예: "한식 > 국밥", "일식 > 돈까스")를
`packages/shared/data`의 질환-음식 규칙의 키워드/food_tag와 매칭해서
경고·추천을 만듭니다. 카카오 카테고리 → 우리 규칙으로 잇는 매핑 테이블이
이 모듈의 핵심 작업입니다.
