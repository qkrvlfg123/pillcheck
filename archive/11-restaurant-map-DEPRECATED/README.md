# 11 · 맞춤 맛집 지도 (보류)

> 이 모듈은 범위를 약물-약물 상호작용으로 좁히면서 보류됨. 구현 코드는 없고 아래 기획만 남아 있음. 현재 11번 앱은 약국·병원 지도(`apps/11-pharmacy-map`)임. 아래에서 말하는 질환-음식 규칙은 `packages/shared`가 아니라 `archive/office_disease_food_rules.json`으로 옮겨져 있음.

지도에서 주변 맛집을 찾고, 내 질환·복용약 기준으로 무엇을 피하고 무엇을 고를지
안내받는 서비스로 기획함. 질환-음식 규칙 데이터를 위치 서비스에 적용하는 모듈임.

## 기획한 기능

1. 지역·역명으로 주변 맛집 검색 (지도에 마커 표시)
2. 사용자 프로필(질환·복용약) 입력
3. 각 맛집의 카테고리/메뉴를 프로필 기준으로 필터링
   - 역류성식도염 → 튀김·마라 집에 "자극적일 수 있어요" 경고
   - 통풍전단계 → 곱창·맥주 집에 주의 표시
   - 순한·담백한 집을 우선 추천
4. 추천/주의의 이유를 함께 표시

## 기존 맛집 지도와 다른 점

기존 맛집 지도는 평점 높은 집을 보여 줌. 이 모듈은 사용자 조건에 맞는 집을
보여 주는 것을 목표로 함. 질환-음식 규칙(고령자 + 직장인)을 지도
검색 결과에 적용하는 것이 다른 점임.

## 스택 (계획)

- 카카오 로컬 API: 키워드로 맛집 검색 + 좌표 + 카테고리
- 카카오맵 JavaScript SDK: 지도·마커 표시
- 필터링 엔진: 질환-음식 규칙
- (선택) 네이버 지역검색 API: 보조 채널

### 카카오 로컬 API를 택한 이유

"강남역 맛집" 같은 키워드 검색, 좌표 반환, 카테고리 분류를 함께 제공해
국내 맛집 검색에 맞다고 판단함. 네이버 지역검색은 결과가 최대 5건이라 (기록)
목록 서비스에는 제약이 큼.

## 데이터 연결

카카오가 주는 식당 카테고리(예: "한식 > 국밥", "일식 > 돈까스")를
질환-음식 규칙의 키워드/food_tag와 매칭해서 경고·추천을 만드는 방식임.
카카오 카테고리를 규칙으로 잇는 매핑 테이블이 이 모듈의 주된 작업임.

> 참고용 안내이며 진단·처방이 아님. "이 집은 먹으면 안 된다"가 아니라
> "이런 점을 참고하세요" 톤으로 안내함.
