# 음성 비서 — Claude Code 프롬프트 가이드

10번 챗봇이 먼저 동작해야 합니다. 챗봇의 `/chat`을 음성으로 감싸는 방식.

---

## 1단계 · 음성 입출력 뼈대 (가장 간단한 버전)

```
브라우저 Web Speech API로 음성 입출력 데모를 만들어줘.
- 마이크 버튼을 누르면 음성을 텍스트로 변환(STT)
- 변환된 텍스트를 화면에 표시
- 아무 텍스트나 음성으로 읽어주는(TTS) 버튼
설치 없이 브라우저에서 바로 되는 걸로. 고령자 대상이라 버튼 아주 크게.
```

## 2단계 · 챗봇 연결

```
1단계 음성 입력을 10번 챗봇(../10-review-chatbot)의 /chat에 연결해줘.
- 말한 내용(STT 결과)을 /chat에 보내고
- 답변을 받아서 화면에 표시 + TTS로 읽어주기
- 챗봇 서버 주소는 설정으로 뺄 것
```

## 3단계 · 약 상담 음성 흐름

```
"타이레놀이랑 혈압약 같이 먹어도 돼요?" 같은 약 질문을 말로 하면,
챗봇의 약물 상담 결과를 받아서 음성으로 읽어주게 해줘.
- 위험한 조합이면 목소리 안내 + 화면에 빨간 경고
- 천천히, 또박또박 읽어주도록(TTS 속도 조절)
```

## 4단계 · 접근성 마무리

```
고령자 접근성을 점검해줘.
- 마이크 버튼은 화면 중앙에 크게
- 듣기 어려울 때 다시 듣기 버튼
- 인식 실패 시 "다시 말씀해 주세요" 안내
- "의료기기 아님, 참고용" 고지를 화면과 음성 안내 첫머리에
```

---

## 주의

- Web Speech API는 브라우저(특히 Chrome)에서 잘 되고, 한국어 지원 확인 필요.
- 음성이라 더더욱 단정적 표현 금지. "약사와 상의하세요"를 꼭 음성에 포함.
