# 음성 비서 (Voice Assistant)

10번 챗봇을 **말로** 쓰는 화면 — 마이크 버튼을 누르고 약에 대해 물어보면 음성으로 답해줍니다. 타이핑이 어려운 고령자를 위한 입구입니다.

## 주요 기능

- **음성으로 질문** — 큰 마이크 버튼을 누르고 말하면 브라우저 음성 인식(STT)이 한국어(`ko-KR`)로 받아씀
- **음성으로 답변** — 답을 브라우저 음성 합성(TTS)으로 읽어줌. 고령자 배려로 조금 느린 속도(rate 0.95)
- **다시 듣기 / 그만 듣기** — 🔊 마지막 답변 다시 재생, ⏹ 읽는 도중 중지
- **긴 리포트는 짧게** — 약물 상담 리포트를 다 읽지 않고 **위험도 + 핵심 + 상담 안내**만 요약해 읽어줌
- **화면에도 표시** — 인식된 말과 답변 전문을 큰 글씨로 함께 보여줌
- 답변 내용은 10번 챗봇 그대로 — 약물 4축 엔진(병용금기 · 성분중복 · 다제약물 · 노인주의)과 리뷰 RAG

### 작동 흐름

```
말하기 → [브라우저 STT] → 텍스트 → [10 챗봇 /chat] → 답변 → [브라우저 TTS] → 듣기
```

**왜 이 구조인가**

- 음성 입출력은 **브라우저 내장** — 무료, 설치 없음, 한국어 지원, API 키 노출 위험 없음
- 똑똑한 답변은 **10 챗봇에 위임** — 판정 로직을 두 곳에 두지 않음

## 실행 방법

이 화면은 **10번 챗봇 서버가 함께 서빙**합니다. 별도 서버가 필요 없습니다.

```bash
cd apps/10-review-chatbot
pip install -r requirements.txt
uvicorn app.main:app --reload
```

→ 브라우저에서 **http://localhost:8000/voice** 접속

> `apps/voice-assistant/index.html`은 같은 화면의 단독 사본입니다.
> 따로 띄울 경우 `/chat` 요청이 챗봇 서버에 닿아야 하므로, 파일 안의
> `API_BASE`를 `"http://localhost:8000"`으로 바꾸고 챗봇 쪽 CORS를 허용해야 합니다.
> **가장 간단한 방법은 `/voice`로 접속하는 것입니다.**

### Vercel 배포

공개 배포본(https://voice-assistant.vercel.app)은 `/chat`을 **Vercel 서버리스 함수**
(`api/chat.py`)가 처리하므로 별도 챗봇 서버 없이 단독으로 동작합니다.
`vercel.json`의 rewrite가 `/chat` → `/api/chat`을 연결해 주기 때문에 `index.html`은
고치지 않았습니다(10 챗봇의 `static/voice.html`과 동일하게 유지).

> **엔진은 `apps/10-review-chatbot` 원본을 배포 편의상 `api/_bundle/`에 번들한 사본입니다.**
> Vercel 함수가 Root Directory 바깥 파일을 번들하지 못해 복사했으며, 원본이 바뀌면
> 다시 복사해야 합니다. 이유와 재복사 명령은 `api/chat.py` 상단 주석에 있습니다.
> 리뷰 RAG는 키가 없어 기존 폴백 문구를 그대로 돌려줍니다(약물 상담은 키 없이 동작).

### 브라우저

음성 인식은 **Chrome · Edge**에서 가장 잘 동작합니다. 마이크 권한을 허용해 주세요.
(Safari·Firefox는 음성 인식이 제한되거나 동작하지 않을 수 있습니다.)

## 기술 스택

| 항목 | 내용 |
| --- | --- |
| 구성 | HTML · CSS · 바닐라 JavaScript 파일 하나 (`index.html`, 빌드 없음) |
| 음성 인식 | Web Speech API — `SpeechRecognition` / `webkitSpeechRecognition` (`ko-KR`) |
| 음성 합성 | Web Speech API — `speechSynthesis` (`ko-KR`) |
| 백엔드 | `apps/10-review-chatbot`의 `POST /chat` |
| 필요한 키 | **불필요** (10 챗봇 서버가 떠 있어야 함) |

## 주의사항

- **이 서비스는 의료기기가 아닙니다.** 진단·처방을 하지 않으며 참고용 안내입니다.
  **최종 판단은 의사·약사가 합니다.**
- **음성 답변은 요약본입니다.** 위험도와 핵심만 읽어주므로, 자세한 근거는 화면의 전문이나
  웹 채팅 화면(http://localhost:8000)에서 확인하세요.
- 음성 인식은 약 이름을 **잘못 알아들을 수 있습니다.** 화면에 표시된 인식 결과가 맞는지 꼭 확인하세요.
- 10 챗봇이 키 없이 실행 중이면 판정 근거가 데모 데이터(`DEMO_UNVERIFIED`)입니다.
  실제 복약 판단에 사용하지 마세요.
- 음성은 주변에 들립니다. 복용 중인 약은 민감한 개인정보이니 **공공장소에서는 주의**하세요.
