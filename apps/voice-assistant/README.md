# 음성 비서 (Voice Assistant)

10 챗봇을 **음성으로** 쓸 수 있게 해주는 화면. 말로 물어보고, 답을 음성으로 듣습니다.
고령자가 타이핑 없이 쓸 수 있도록 큰 마이크 버튼으로 설계했습니다.

## 어떻게 작동하나

1. 마이크 버튼을 누르고 말함 → **브라우저 음성 인식(STT)**이 텍스트로 변환
2. 그 텍스트를 **10 챗봇 서버(`/chat`)**로 보냄 → 약물 상담/리뷰 답변
3. 답을 **브라우저 음성 합성(TTS)**으로 읽어줌 (약 위험도는 짧게 요약해서)

```
말하기 → [브라우저 STT] → 텍스트 → [10 챗봇] → 답변 → [브라우저 TTS] → 듣기
```

## 왜 이 구조인가

- **음성 입출력은 브라우저 내장** — 무료, 설치 없음, 한국어 지원, API 키 노출 위험 없음
- **똑똑한 답변은 10 챗봇** — 약물 4축 엔진(→식약처 DUR) + Gemini RAG
- 음성 답변은 긴 리포트를 다 읽지 않고 "위험도 + 핵심 + 상담 안내"만 짧게

## 실행 방법

이 화면은 **10 챗봇 서버가 함께 서빙**합니다. 별도 서버가 필요 없어요.

```bash
# 10 챗봇을 실행하면 음성 화면도 같이 떠요
cd apps/10-review-chatbot
pip install -r requirements.txt
uvicorn app.main:app --reload
```

- 챗봇 화면: http://localhost:8000
- **음성 비서: http://localhost:8000/voice**

## 주의

- **크롬(Chrome)에서 가장 잘 됩니다.** 음성 인식(Web Speech API)이 브라우저마다
  지원이 달라서, 크롬 권장입니다.
- 처음 마이크 쓸 때 브라우저가 **마이크 권한**을 물어봐요. 허용해야 작동합니다.
- 배포(https) 환경에서 더 안정적입니다. (로컬 http도 크롬은 됩니다)

## 파일

- `index.html` — 음성 비서 화면 (STT + TTS + 챗봇 연결)
  - 10 챗봇의 `static/voice.html`로도 복사되어 `/voice`에서 서빙됩니다.

## 접근성 배려

- 큰 마이크 버튼(120px), 큰 글씨(19px+)
- 음성 속도 0.95배로 조금 천천히 읽음
- "다시 듣기" / "그만 듣기" 버튼
- 위험도 색 표시 (높음=빨강, 보통=주황, 낮음=청록)
- 진단·처방이 아닌 참고용임을 화면·음성에 명시

## 참고

- 음성 답변도 단정하지 않아요. "약사와 상담하세요"를 항상 포함합니다.
- 실제 판정은 10 챗봇의 약물 엔진(→식약처 DUR)이 합니다.
