# 08 · SaaS 랜딩 페이지

필체크의 서비스 소개 랜딩 페이지 — "여러 약, 같이 먹어도 괜찮을까요?"라는 질문으로 시작해 약 조합을 직접 눌러보게 하는 한 장짜리 Next.js 페이지입니다.

## 주요 기능

- **히어로 섹션** — "여러 약, 같이 먹어도 괜찮을까요?" 한 문장으로 서비스를 설명하고 상담 시작 버튼으로 연결
- **인터랙티브 데모** (`components/DrugDemo.tsx`) — 이 페이지의 시그니처.
  일상어 조합 버튼(목감기약 + 두통약, 우울증약 + 편두통약, 수면제 + 신경안정제)을
  누르면 각 약의 **제품명 예시**와 **위험도 · 쉬운 말 안내**가 펼쳐집니다.
- **기능 소개 카드 3종** — 상호작용 확인 / 약물 정보 / 약국·병원 찾기
- **타겟 소개** — 여러 약을 드시는 어르신, 바쁜 직장인
- **고지 영역** — 의료기기가 아니며 참고용이라는 안내를 화면에 상시 노출
- **고령자 접근성** — 기본 폰트 18px 이상, 큰 버튼, 고대비 색상, 모션 최소화(`prefers-reduced-motion`) 대응

## 실행 방법

외부 API 키가 필요 없습니다. 설치하고 바로 띄우면 됩니다.

```bash
cd apps/08-saas-landing
npm install       # 처음 한 번만
npm run dev       # → http://localhost:3000
```

배포 전 빌드 확인:

```bash
npm run build     # 프로덕션 빌드 (반드시 통과 확인)
npm run start     # 빌드된 앱 실행
```

### 파일 구성

```
app/page.tsx            메인 랜딩 (히어로 · 데모 · 기능 · 타겟 · 고지 · 푸터)
app/layout.tsx          레이아웃 · 폰트
app/globals.css         전역 스타일 · 접근성(포커스, 모션 최소화)
components/DrugDemo.tsx 약 조합 인터랙티브 데모 (클라이언트 컴포넌트)
tailwind.config.ts      디자인 토큰 (딥 틸 + 크림 + 앰버/코럴)
```

## 주의사항

- **이 서비스는 의료기기가 아닙니다.** 진단·처방을 하지 않으며, 모든 안내는 참고용이고
  **최종 판단은 의사·약사가 합니다.**
- 랜딩의 데모는 **하드코딩된 미리보기**입니다. 실제 판정은 10번 챗봇 + 식약처 DUR이 담당합니다.
  이 데모 결과를 실제 복약 판단에 사용하지 마세요.
- 데이터베이스에 없다고 해서 안전한 것은 아닙니다. 복용 전 반드시 의사·약사와 상담하세요.
- 페이지는 랜딩 한 개만 유지합니다. 라우팅·상태관리를 복잡하게 만들지 않습니다.
