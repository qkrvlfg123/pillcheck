# 11 · 주변 약국·병원 지도

카카오맵으로 내 주변 **약국 · 병원 · 내과**를 찾아주는 HTML 한 장짜리 화면 — 챗봇에서 주의가 확인됐을 때 "그럼 어디서 상담하지?"에 답하는 상담 연결 담당입니다.

## 주요 기능

- **주변 검색** — 현재 위치(브라우저 위치 권한) 또는 지금 보고 있는 지도 범위에서 검색
- **필터 버튼 3종** — 💊 약국 / 🏥 병원 / 🩺 내과
  (약국·병원은 카카오 카테고리 코드 `PM9`·`HP8`, 내과는 키워드 검색)
- **지도 마커 + 목록** — 마커를 누르면 이름이 뜨고, 목록에서 **전화 걸기 · 카카오맵 길찾기**로 바로 연결
- **상담 연결 배너** — 챗봇에서 `?from=pillcheck&risk=high`로 들어오면
  "복용 중인 약에서 주의가 필요한 조합이 확인됐어요. 가까운 약국에서 약사와 상담해보세요." 배너를 표시
- **고령자 배려** — 큰 글씨, 큰 버튼, 높은 대비

### 서비스 흐름 안에서의 위치

```
10 챗봇에서 약 상호작용 확인 → 위험 발견 → [이 화면] 주변 약국·병원 안내 → 실제 상담
```

필체크의 원칙은 "진단·처방을 하지 않는다, 최종 판단은 약사·의사"입니다.
그래서 마지막에 **사람에게 연결하는 화면**이 있어야 서비스가 닫힙니다.

## 실행 방법

백엔드가 필요 없는 순수 웹페이지입니다. 카카오 JavaScript 키만 넣으면 됩니다.

### 1. 카카오 JavaScript 키 받기

1. [developers.kakao.com](https://developers.kakao.com) 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** (앱 이름: 필체크 등)
3. **앱 키 → JavaScript 키** 복사
4. **플랫폼 → Web → 사이트 도메인 등록** (등록하지 않으면 지도가 뜨지 않습니다)
   - 로컬 테스트: `http://localhost:5500` (쓰는 포트에 맞게)
   - 배포 시: 실제 도메인

### 2. 키 넣기

`index.html` 상단의 `KAKAO_JS_KEY` 값을 **본인 키로 교체**합니다.

```js
const KAKAO_JS_KEY = "여기에_본인_JavaScript_키";
```

### 3. 실행

VS Code **Live Server** 확장으로 `index.html`을 열거나, 아무 정적 서버로 띄웁니다.

```bash
cd apps/11-pharmacy-map
python -m http.server 5500      # → http://localhost:5500
```

> 파일을 더블클릭해 `file://` 로 여는 방식은 위치 권한·도메인 등록 때문에 동작하지 않습니다.
> 반드시 `http://localhost` 로 접속하세요.

## 기술 스택

| 항목 | 내용 |
| --- | --- |
| 구성 | HTML · CSS · 바닐라 JavaScript 파일 하나 (`index.html`, 빌드 없음) |
| 지도 | 카카오맵 JavaScript SDK + `services` 라이브러리(장소 검색) |
| 위치 | 브라우저 Geolocation API |
| 서버 | 불필요 (정적 호스팅 가능) |
| 필요한 키 | 카카오 JavaScript 키 (**필수**) |

## 주의사항

- **이 서비스는 의료기기가 아닙니다.** 진단·처방을 하지 않으며 참고용 안내입니다.
  **최종 판단은 의사·약사가 합니다.** 이 화면은 그 상담을 연결해줄 뿐입니다.
- 저장소에 들어 있는 `KAKAO_JS_KEY`는 **데모용 값**입니다. 반드시 본인 키로 교체하세요.
  JavaScript 키는 브라우저에 노출되는 공개 키이므로, 보안은 **카카오 개발자 콘솔의
  사이트 도메인 등록**으로 지킵니다(등록된 도메인에서만 동작).
- 영업시간·휴무·전화번호 등은 카카오 장소 데이터를 그대로 보여주는 것이라 **실제와 다를 수 있습니다.**
  방문 전 전화로 확인하세요.
- 위치 권한을 거부하면 현재 위치 대신 지도 화면 범위를 기준으로 검색합니다.
- 응급 상황이라면 이 화면을 찾지 말고 **119**에 연락하세요.
