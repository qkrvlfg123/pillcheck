# 11 · 주변 약국·병원 지도 (완성 코드)

약 상담에서 주의가 나오면 **가까운 약국·병원을 지도에서 찾아** 상담하러 갈 수
있게 하는 화면. 필체크의 "상담 연결" 담당.

## 무엇이 되나

- 내 위치(또는 지도 화면) 주변의 약국·병원·내과를 지도에 표시
- 필터 버튼: 약국 / 병원 / 내과
- 마커 클릭 → 이름 표시, 목록에서 전화·길찾기(카카오맵) 버튼
- 챗봇에서 `?from=pillcheck&risk=high`로 들어오면 "약사와 상담하세요" 배너

## 왜 이 화면인가

필체크의 원칙은 "진단·처방을 하지 않는다, 최종 판단은 약사·의사"입니다.
그렇다면 "그럼 어디서 상담하지?"에 답해야 서비스가 완성됩니다.
약 상호작용 확인 → 위험 발견 → **주변 약국/병원 안내** → 실제 상담.
이 흐름이 서비스를 닫아줍니다.

## 실행 방법

이건 순수 웹페이지(HTML 하나)라 백엔드가 필요 없어요. 카카오 키만 넣으면 됩니다.

### 1. 카카오 JavaScript 키 받기
1. [developers.kakao.com](https://developers.kakao.com) 로그인
2. 내 애플리케이션 → 애플리케이션 추가하기 (앱 이름: 필체크 등)
3. **앱 키 → JavaScript 키** 복사
4. **플랫폼 → Web → 사이트 도메인 등록**:
   - 로컬 테스트: `http://localhost:5500` (또는 쓰는 포트)
   - 배포 시: 실제 도메인

### 2. 키 넣기
`index.html`에서 이 부분을 찾아 `YOUR_JS_KEY`를 본인 키로 바꾸세요:
```html
<script src="//dapi.kakao.com/v2/maps/sdk.js?appkey=YOUR_JS_KEY&libraries=services&autoload=false"></script>
```

### 3. 실행
`index.html`을 브라우저로 열면 됩니다.
로컬 서버로 띄우면 더 안정적이에요 (위치 권한 등):
```bash
# 파이썬이 있으면
python -m http.server 5500
# → http://localhost:5500 접속
```
> VS Code의 "Live Server" 확장을 써도 편해요.

## 카카오 카테고리 코드

- 약국: `PM9`
- 병원: `HP8`
- 내과: 키워드 "내과"로 검색

## 챗봇과 연결

10 챗봇/음성에서 위험이 나오면 이 주소로 보내면 배너가 떠요:
```
11-pharmacy-map/index.html?from=pillcheck&risk=high
```

## 주의

- **카카오맵 키가 없으면** 안내 화면이 뜹니다 (키 넣으라고).
- 위치 정보는 이번 검색에만 쓰고 저장하지 않습니다.
- 영업/진료 시간은 부정확할 수 있으니 "방문 전 확인" 안내를 넣었습니다.
- 카카오맵 출처를 하단에 표기했습니다(이용약관 준수).

## 접근성

- 큰 필터 버튼, 큰 글씨
- 목록 + 지도 동시 표시 (모바일은 세로로 쌓임)
- 전화는 tel: 링크로 바로 걸기
