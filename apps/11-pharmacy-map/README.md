# 11 · 주변 약국·병원 지도

약물 상호작용에서 **위험이 확인되면, 가까운 약국·병원에서 상담**할 수 있도록
주변 약국·의원을 지도에 표시하는 모듈. 필체크의 "상담 연결" 담당.

## 왜 이 모듈인가 (필체크와 연결)

필체크의 핵심 원칙은 "우리는 진단·처방을 하지 않는다, 최종 판단은 약사·의사"
입니다. 그렇다면 **"그럼 어디서 상담하지?"**에 답해야 완결됩니다.
약 상호작용 확인 → 위험 발견 → **주변 약국/병원 안내** → 실제 상담.
이 흐름이 서비스를 닫아줍니다. (기존 맛집지도를 이걸로 대체)

## 무엇을 만드나

1. 내 위치 또는 지역 검색으로 주변 약국·병원 표시
2. 지도 위 마커 + 목록(이름, 거리, 진료/영업 여부)
3. 약국 / 내과 / 병원 필터
4. 마커 클릭 → 전화·길찾기(카카오맵 링크)
5. (연계) 필체크에서 위험이 나온 경우 "가까운 약국에서 상담하세요" 배너로 유입

## 스택

- **카카오 로컬 API** — "약국", "내과" 등 카테고리로 주변 검색
- 카카오맵 JS SDK — 지도·마커
- (선택) 공공데이터 "전국 약국 정보", "병원 정보" 조회 서비스로 보강
