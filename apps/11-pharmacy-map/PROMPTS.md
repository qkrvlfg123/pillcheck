# 11 약국·병원 지도 — Claude Code 프롬프트 가이드

---

## 0단계 · 준비

- 카카오 개발자(https://developers.kakao.com) 앱 생성 → JavaScript 키 + REST 키
- 카카오맵 플랫폼에 사이트 도메인 등록
- 키는 `.env`에 저장, git 금지

## 1단계 · 지도 + 주변 약국 표시

```
카카오맵으로 주변 약국을 보여주는 페이지를 만들어줘.
- 사용자 위치 권한을 받아 현재 위치 중심으로 지도 표시
  (권한 거부 시 지역명 검색으로 대체)
- 카카오 로컬 API에서 카테고리 "약국"(코드 PM9)으로 주변 검색
- 지도에 마커 + 오른쪽에 목록(이름, 거리)
- 고령자 대상이라 글씨·마커 크게
JS 키는 .env에서 읽어. 먼저 구조 계획부터.
```

카카오 로컬 카테고리 코드 참고: 약국 `PM9`, 병원 `HP8`.

## 2단계 · 병원/내과 필터

```
상단에 필터 버튼을 추가해줘: [약국] [병원] [내과].
- 약국: 카테고리 PM9
- 병원: 카테고리 HP8
- 내과: 키워드 "내과"로 검색
선택에 따라 마커와 목록이 바뀌게.
```

## 3단계 · 마커 상세 + 전화·길찾기

```
마커를 클릭하면 정보창을 띄워줘.
- 이름, 주소, (있으면) 전화번호
- "전화걸기"(tel: 링크), "길찾기"(카카오맵 길찾기 URL) 버튼
- 고령자 배려로 버튼 크게
```

## 4단계 · 필체크 연계 배너

```
쿼리 파라미터로 ?from=pillcheck&risk=high 처럼 들어오면
상단에 안내 배너를 보여줘:
"복용 중인 약에서 주의가 필요한 조합이 확인됐어요.
 가까운 약국에서 약사와 상담해보세요."
이렇게 10번 챗봇/음성에서 위험이 나오면 이 지도로 자연스럽게 유입되게.
```

## 5단계 · 마무리

```
접근성·반응형 점검하고 실행법을 README에 정리해줘.
- "영업/진료 시간은 실제와 다를 수 있으니 방문 전 확인하세요" 안내
- 카카오맵 출처·로고 표기 규정 확인
- 위치정보는 저장하지 않고 이번 조회에만 사용한다는 안내
```

---

## 주의

- 위치정보(위경도)는 저장하지 말고 조회에만 사용. 개인정보 최소.
- 영업시간 데이터는 부정확할 수 있으니 단정하지 말 것.
- 공공데이터 "전국 약국정보 서비스"로 보강하면 더 정확하나, 카카오만으로도
  기본 동작함.
- API 키는 .env, git 금지. JS 키 도메인 제한 필수.
