# 09 · 건강정보 블로그

고령자 눈높이의 **건강정보 블로그**. 글 작성·조회·좋아요가 가능한 풀스택 웹앱.
챕터 9의 핵심은 **REST API + 데이터베이스(Supabase) + RLS 보안 정책**입니다.

## 무엇을 만드나

- 글 목록 / 글 상세 보기
- 글 작성 (건강 정보 콘텐츠)
- 좋아요 기능
- 인증 + **RLS(Row Level Security)** 정책 — 자기 글만 수정/삭제 가능

## 왜 이 프로젝트인가 (플랫폼 연결)

이 블로그의 콘텐츠는 아무 주제가 아니라 **고령자 건강정보**입니다.
`packages/shared`의 질환·약물 데이터를 콘텐츠 소스로 활용할 수 있습니다
(예: "고혈압에 주의할 음식", "함께 먹으면 안 되는 약" 같은 글).

## 스택

- Next.js + TypeScript
- **Supabase** (Postgres + Auth + RLS)
- 배포: Vercel

책 원본은 안티그래비티를 쓰지만, 이 프로젝트는 **Claude Code**로 구현합니다.

## RLS가 왜 중요한가

Supabase는 DB가 클라이언트에 바로 노출되는 구조라, 테이블마다 "누가 이 행을
읽고 쓸 수 있는가"를 RLS 정책으로 막지 않으면 **아무나 남의 글을 수정·삭제**할
수 있습니다. 이 챕터의 핵심 학습 포인트입니다.
