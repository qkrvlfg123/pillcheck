# packages/shared — 약물 상호작용 엔진 (필체크 코어)

필체크(PillCheck)의 심장부. 여러 약을 함께 복용할 때의 위험을 **4개 축**으로
분석합니다. 챗봇(10)·약국병원지도(11)·음성이 모두 이 엔진을 공유합니다.

## 4개 분석 축

| 축 | 무엇 | 근거 |
| --- | --- | --- |
| 1. 병용금기·주의 | 두 약을 함께 쓰면 안 되는/조심할 조합 | 식약처 DUR 병용금기 |
| 2. 효능군·성분 중복 | 같은 계열·성분이 겹쳐 과용량 되는 위험 | 성분 태그 + DUR 효능군중복 |
| 3. 다제약물 | 약이 3·4개↑ 늘수록 상호작용 쌍이 급증 | 조합 수 계산(nC2) |
| 4. 노인·연령 주의 | 특정 연령대에 주의가 필요한 약 | 식약처 DUR 노인주의 |

## 판정 원칙 (가장 중요)

- **약물 상호작용의 공식 근거는 식약처 DUR API입니다.**
- DUR 서비스키가 있으면 공식 조회(`[O] DUR 공식`), 없으면 데모 데이터로
  참고 표시하되 **미검증임을 명시**(`[!] 미검증 데모`)합니다.
- 이 엔진은 스스로 의학적 판단을 만들지 않습니다.
- **시너지(약을 조합해 효과를 높임)는 다루지 않습니다** — 그건 처방 영역입니다.
  위험(금기·주의·중복·다제)만 안내합니다.

## 실행

```bash
cd engine && python3 drug_interaction.py
```

효능군 중복 탐지 예시:
- 감기약 + 진통제 → 아세트아미노펜/진통 성분 중복 경고
- SSRI + 트립탄 → 세로토닌 작용 중복 (세로토닌증후군 주의)
- 벤조디아제핀 + 수면제 → 중추억제 중복 (과진정 주의)

다제약물 예시:
- 약 3개 → 3쌍 검사, 4개 → 6쌍, 5개↑ → 다제약물 위험 경고


## 제품명으로도 검색됩니다

계열명(성분)뿐 아니라 **실제 제품명**으로 입력할 수 있습니다.
게보린·타이레놀·이지엔6에이스·판피린큐·펜잘큐·은교산 등 흔한 제품을
성분으로 변환해 분석합니다.

핵심 예시 — **아세트아미노펜 중복 탐지**:
- 게보린 + 타이레놀 → 둘 다 아세트아미노펜 함유 → 간독성 위험 경고
- 감기약(판피린) + 두통약(타이레놀) → 아세트아미노펜 중복

같은 브랜드도 종류별 성분이 다릅니다(이지엔6에이스=아세트아미노펜,
이지엔6프로=덱시부프로펜). 제품 매핑에 없는 제품은 식약처 e약은요 API로
조회합니다. 근거는 SOURCES.md 참조.


## 위험도 표시 방식 (점수 아님, 근거 명시)

**점수(숫자)를 쓰지 않습니다.** 대신 규칙 기반 레벨(낮음/보통/높음)을 쓰고,
**그 레벨이 나온 이유를 항상 함께** 보여줍니다.

레벨 결정 규칙(위에서부터 먼저 걸리는 것):
- **높음**: 병용금기 '위험' 1건↑, 또는 성분중복 '위험' 1건↑, 또는 다제약물 5가지↑
- **보통**: '주의' 항목 1건↑, 또는 다제약물 4가지
- **낮음**: 위험·주의 발견 없음

예) "높음 — 같은 성분이 겹쳐 위험한 중복이 1건 있어요" 처럼 결론과 근거가 함께.

영양소 순위도 '등장 횟수 점수'가 아니라, **어떤 조건(직업·나이) 때문에 관련되는지**
근거로 설명합니다. 예) "비타민D — 교대근무·오래앉음·30대 3가지 조건에 해당".

## 식약처 DUR 연동

data.go.kr에서 "DUR품목정보" 활용신청(무료·자동승인) 후:
```bash
export DUR_SERVICE_KEY="발급받은키"
cd engine && python3 drug_interaction.py
```
DUR은 병용금기·노인주의·특정연령금기·효능군중복 등을 성분별로 제공합니다.
연동 상세는 `SOURCES.md` 참조.

## 다른 모듈에서 사용

```python
import sys
sys.path.append("../../packages/shared/engine")
from drug_interaction import check, format_report

result = check(["와파린", "부루펜", "타이레놀"], age=70)
print(format_report(result))
# result["axis1_interactions"], axis2_duplicates, axis3_polypharmacy, axis4_elderly
```

## 한계·고지

- 의료기기가 아니며 진단·처방을 하지 않습니다.
- 데모 데이터는 미검증 참고용이며, 공식 판정은 DUR이 합니다.
- DB 미등재가 안전을 의미하지 않습니다.
- 최종 판단은 의사·약사가 하며, 위험 확인 시 약국·병원 상담을 권합니다.
