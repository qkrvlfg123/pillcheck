# 근거 출처 (SOURCES)

필체크의 규칙이 어떤 근거에 기반하는지 정리한 문서.
규칙은 공식 자료·진료지침을 근거로 구축했으며, 약사·의사의 검토는 거치지 않음.

## 근거수준 체계

각 상호작용 규칙에는 근거수준이 부여되어 있음(`evidence_level`).

| 수준 | 뜻 |
| --- | --- |
| 강(STRONG) | 식약처 DUR 병용금기·공식문서 금기에 명시. 기계적 확인 가능 |
| 중(MODERATE) | 약학정보원·진료지침·교과서 등 널리 인정된 기전/가이드라인 |
| 약(LIMITED) | 일반적 주의사항·경향 수준. 참고용, 개인차 큼 |

현재 상호작용 규칙 23건: 강 2 / 중 15 / 약 6. 각 규칙의 `evidence_note`에
구체 근거가, `source_ids`에 출처가 연결되어 있음.
`engine/verify_evidence.py`가 모든 규칙의 출처·근거수준·검증 상태 완비 여부를 검사함.

## 검증 상태

근거수준과 별개로, 이 프로젝트에서 실제 원문을 확인했는지를 구분함.

| 상태 | 뜻 | 표시 |
| --- | --- | --- |
| 원문확인(VERIFIED_SOURCE) | 약학정보원·식약처 등 실제 출처를 이 프로젝트에서 확인 | ✓원문확인 |
| 기전추론(MECHANISM_INFERRED) | 널리 알려진 약리 기전이나 특정 원문은 미대조 | △기전추론 |

현재 상호작용 23건: 원문확인 12건 / 기전추론 11건.
"기전추론"은 표준 약리 기전에 따른 것이지만, 이 프로젝트에서 특정 문헌을
대조하지 않았다는 표시임. 리포트와 근거 장부에 이 구분이
그대로 노출되며, 실제 판정은 식약처 DUR·약사 확인이 우선함.

성분 태그(`ingredient_tags`) 배정 기준은 `data/ingredient_tag_basis.json`에
정리되어 있음. 각 태그를 그 약에 붙인 기준과 근거를 적어 둠.

## 공식 근거원

| ID | 출처 | URL |
| --- | --- | --- |
| MFDS_DUR_API | 식약처 DUR 품목정보 OpenAPI | data.go.kr/data/15059486 |
| KIDS_DUR_FILE | 한국의약품안전관리원 병용금기약물 | data.go.kr/data/15089525 |
| HIRA_DUR | 건강보험심사평가원 DUR 목록 | data.go.kr/data/15127983 |

`data/evidence_sources.json`에는 위 5곳을 포함해 13곳이 등록돼 있음. 나머지(Beers Criteria 2023, 식약처 타이레놀정 허가사항, 약학정보원 개별 자료 등)는 `EVIDENCE_LEDGER.md`의 근거원 표에 있음.

## 약물 상호작용과 식약처 DUR

기본 판정은 직접 구축한 규칙 데이터(`drug_drug_interactions_demo.json`)로 함.
각 항목에 근거수준(`evidence_level`)과 검증 상태(`verification`)가 표시되어 있음.
식약처 DUR 공식 데이터는 옵션(`use_dur`)으로 조회해 자체 규칙에 덧붙임.

- 식품의약품안전처 의약품안전사용서비스(DUR) 품목정보 API
  https://www.data.go.kr/data/15059486/openapi.do
  (병용금기·노인주의·특정연령금기·용량주의 등, 무료·자동승인)
- 의약품 제품 허가정보 API (제품명·영문 성분명 → 품목기준코드)
  https://www.data.go.kr/data/15095677/openapi.do

`packages/shared/dur_client/`에 이 API들의 클라이언트가 있음(`dur_api.py`, `drug_permit_resolver.py`, `dur_check.py`).
엔진의 `check(..., use_dur=True)`가 이를 호출해 결과를 `result["dur"]`에 담음. 기본값은 꺼짐이며 서비스키가 필요함.
DUR 병용금기는 절대 금기만 등재하므로 자체 규칙을 대체하지 않고 보강만 함.

### 참고: DUR 검증 시 대조 가능한 공개 자료
- 와파린 + NSAIDs 출혈 위험: RE-LY 연구 사후분석, 약학정보원 와파린 정보
- 자몽-약물 상호작용, 병용금기: 식약처 의약품안전나라 상호작용 정보
  https://nedrug.mfds.go.kr/bbs/12

## 질환-음식 규칙 (직장인), 진료지침·학술 근거

이 규칙 데이터는 현재 범위에서 제외되어 `archive/office_disease_food_rules.json`으로 옮겨져 있음.
각 규칙의 `evidence` 필드에 출처가 매핑되어 있음.

### 위식도역류(역류성식도염)
- 대한소화기학회 위식도역류질환 가이드라인(2025), Cleveland Clinic
- 근거: 고지방·카페인·초콜릿·박하는 하부식도괄약근을 이완, 매운 음식(캡사이신)·
  감귤류·탄산은 식도 점막을 직접 자극해 역류 악화.

### 위염
- 소화기 임상 자료(위점막 자극 기전)
- 근거: 매운·짠 자극, 알코올·카페인이 위산 분비를 늘리고 점막을 손상.

### 불면·수면장애
- 수면정신생리 학회지 2017;24(1) (수면장애와 알코올),
  약학정보원 Pharmacotherapy Today 불면증 치료(2024)
- 근거: 카페인 각성 효과 6~8시간 지속, 알코올은 초기 진정 후 수면 후반부 교란.

### 고요산혈증·통풍전단계
- 한국형 통풍 진료지침 (대한내과학회지 2023, doi.org/10.3904/kjim.2023.206),
  대한류마티스학회지
- 근거: 맥주(알코올+퓨린)·내장·붉은고기·과당음료가 요산 상승. 한국은 회식·과음
  문화로 통풍 위험이 특히 높음.

### 대사증후군·당뇨전단계
- 대한당뇨병학회 진료지침, 대사증후군 식이 관리 자료
- 근거: 정제탄수화물·가당음료가 혈당 급등·인슐린 저항성 악화.

## 고령자 질환-음식 규칙 (기존 데이터셋)

고혈압·당뇨·통풍 등 고령자 질환 규칙은 별도 레포
`kiobridge-health-ruleset`의 데이터셋을 참고함. 해당 데이터는
2023 노인실태조사, 질병관리청, 대한당뇨병학회 가이드라인에 근거해 설계되었으며
규칙별 출처 ID가 매핑되어 있음 (기록).

---

## 원칙

- 규칙은 공식 진료지침·학술 자료·정부 공개데이터에 근거함.
- 기본 판정은 자체 규칙 데이터로 하고, `use_dur`를 켜면 식약처 DUR 조회 결과를 덧붙임. 코드는 조회·정리·안내만 하며 스스로 의학적 판단을 만들지 않음.
- DB 미등재가 안전을 의미하지 않음.
- 모든 정보는 참고용이며 최종 판단은 의사·약사가 함.

## 제품명 → 성분 매핑 (product_ingredient_map.json)

흔한 국내 제품의 성분을 확인해 등재함. 같은 브랜드도 종류별 성분이
다르므로(예: 이지엔6 시리즈) 제품 단위로 매핑함.

주요 확인 출처:
- 식약처 의약품통합정보시스템 (nedrug.mfds.go.kr): 제품별 주성분
- 식약처 e약은요 / 의약품 제품허가정보 API: 실시간 조회 (매핑에 없는 제품)
- 이지엔6 시리즈 성분: 식약처 제품정보 + 약사 확인 (기록) (에이스=아세트아미노펜,
  애니=이부프로펜, 프로=덱시부프로펜, 스트롱=나프록센, 이브=이부프로펜+파마브롬)
- 게보린(아세트아미노펜+이소프로필안티피린+카페인), 펜잘큐(아세트아미노펜+
  에텐자미드+카페인): 경향신문/헬스경향 성분 보도 및 식약처 정보

### 제품 단위로 매핑한 이유
같은 "이지엔6"라도 에이스는 아세트아미노펜(타이레놀과 동일), 프로는
덱시부프로펜(NSAID)으로 상호작용이 다름. 아세트아미노펜은
감기약·두통약에 널리 들어 있어, 여러 개를 함께 먹으면 모르는 사이에
하루 최대량을 넘겨 간독성 위험이 생김. 필체크는 이 중복을 잡아냄.

제품 성분·함량은 리뉴얼로 바뀔 수 있으므로 최신은 식약처 API로 확인함.

## 영양소 안내 (nutrition_profiles.json)

직업·나이·생활패턴별 '부족하기 쉬운' 영양소 정보임. 치료·예방 표방이
아니라 일반 영양 정보 참고이며, 약사법·건강기능식품법 원칙을 따름.

주요 근거:
- 삼성서울병원 영양정보: 바쁜 직장인·실내생활자의 비타민D 부족 지적
- 교대근무자 비타민D 연구, 대학 연구활동종사자 비타민D 영양상태 분석(KCI)
- 균형 근거: 비타민D 고용량 보충이 오히려 낙상·골절 위험을 높인다는 보고
  (의협신문) → '무조건 보충'이 아니라 '검사 후 상담' 원칙의 근거
- 멜라토닌은 국내 전문의약품 → 임의복용 안내 금지, 생활습관 개선 우선

### 영양제-약물 상호작용
- 오메가3 + 항응고제(와파린) → 출혈 위험
- 칼슘/철분 + 갑상선약·항생제·골다공증약 → 흡수 방해(복용 간격)

이 상호작용은 약물 엔진과 연계해 함께 점검함.

### 법적 안전선
질병 치료·예방 효과 표방 금지, 특정 제품 판매 유도 금지, 과잉 위험 고지,
전문가 상담 안내를 모든 출력에 포함함.

## 데이터 확장 (제품·영양소·증상·임부)

### 제품명 확장 (총 40종)
혈압약(노바스크·아모디핀·디오반·코자), 당뇨약(다이아벡스·아마릴·자누비아),
고지혈증약(리피토·크레스토·리바로), 위장약(넥시움·가스터), 항생제(오구멘틴·크라비트),
알레르기약(지르텍·알레그라), 갑상선약(씬지로이드) 등을 식약처 의약품통합정보로
성분 확인해 추가함.
- 노바스크=암로디핀, 다이아벡스=메트포르민, 아마릴=글리메피리드,
  자누비아=시타글립틴, 리피토=아토르바스타틴 (식약처/약학정보원 확인)

### 영양소 확장 (총 16종)
아연·엽산·비타민K·코엔자임Q10·비타민E·비타민A 추가.
영양제-약물 상호작용: 비타민K/E/오메가3/코엔자임Q10 + 항응고제(와파린),
아연/철분/칼슘 + 항생제·갑상선약 등.

### 증상 안내 + 임부주의
증상(두통·소화불량·콧물 등)별로 흔히 쓰는 약 '계열'과 주의점 안내.
- 원칙: 특정 제품 '먹어라'가 아니라 계열·주의 안내. 심하면 진료 권유.
- 임부/수유부 주의: 식약처 DUR '임부금기'가 공식 근거. NSAIDs 임신후기 금기 등.
